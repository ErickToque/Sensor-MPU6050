# Comandos importantes

Crear entorno virtual:

```bash
python -m venv venv
```

Activar entorno virtual:

```powershell
.\venv\Scripts\Activate
```

Instalar librerías:

```bash
pip install pyserial pandas matplotlib keyboard
```

Ejecutar programa:

```bash
python archivo.py
```
